# Open Questions

Every time something is unclear, it gets a row here **immediately** — even if it feels stupid,
even if I expect to answer it in ten minutes. This file is supposed to **grow** through the
project. An answered question keeps its row, with the answer and the date.

A question that is still unanswered at the end of the project stays here, marked
`still unknown`. That is an honest result, not a failure.
