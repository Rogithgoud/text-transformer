# Learning Log

Chronological journal — one entry per working session, newest at the bottom. Written the same
day, not reconstructed later. This is the file a reviewer reads first to see how the
understanding actually developed.

Each entry answers four things:

- **Did** — what I built or read
- **Learned** — the concept that landed, in my own words
- **Stuck** — what confused me, and whether it is resolved
- **Next** — the single next step
